================================================================================
FIRESTORE SECURITY RULES - TSY TAXI
================================================================================

This project uses TWO separate Firebase projects:
1. tsytaxi-fcbd3 (Bookings & Customer Data)
2. tsytaxi-7e9b0 (Partners & Partner Management)

Copy and paste the rules for each project in the Firebase Console.

================================================================================
PROJECT 1: tsytaxi-fcbd3 (BOOKINGS)
================================================================================

URL: https://console.firebase.google.com/project/tsytaxi-fcbd3/firestore/rules

Used by: booking.html, admin.html, booking-status.html

RULES TO PASTE:
---

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Bookings collection - Full public access
    match /bookings/{bookingId} {
      allow read: if true;
      allow create: if true;
      allow update: if true;
      allow delete: if true;
    }

    // Users collection - Full public access
    match /users/{userId} {
      allow read: if true;
      allow write: if true;
    }

    // Deny all other collections
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

---

CLICK "PUBLISH" AFTER PASTING


================================================================================
PROJECT 2: tsytaxi-7e9b0 (PARTNERS)
================================================================================

URL: https://console.firebase.google.com/project/tsytaxi-7e9b0/firestore/rules

Used by: superadmin.html, partner-login.html, admin.html (for partner lookup)

RULES TO PASTE:
---

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Partners collection - Full access
    match /partners/{partnerId} {
      allow read: if true;
      allow write: if true;
    }

    // Customers collection
    match /customers/{customerId} {
      allow read: if true;
      allow write: if true;
    }

    // Partner Requests collection
    match /partnerRequests/{requestId} {
      allow read: if true;
      allow create: if true;
      allow update: if true;
      allow delete: if true;
    }

    // Users collection
    match /users/{userId} {
      allow read: if true;
      allow write: if true;
    }

    // Deny all other collections
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

---

CLICK "PUBLISH" AFTER PASTING


================================================================================
AFTER PUBLISHING
================================================================================

1. Wait 10-20 seconds for rules to propagate
2. Clear browser cache (Ctrl+Shift+Delete)
3. Reload admin.html and test partner assignment
4. Check browser console for any remaining permission errors

================================================================================
TROUBLESHOOTING
================================================================================

If still getting permission errors:

1. Verify you published rules in BOTH projects
2. Check you're in the correct Firebase project when publishing
3. Wait 30 seconds and try again
4. Check Firebase Console > Firestore > Rules tab shows "Published" status
5. In browser DevTools > Application > Clear Site Data

================================================================================
SECURITY WARNING
================================================================================

⚠️ THESE RULES ARE FOR DEVELOPMENT ONLY ⚠️

For production:
- Add authentication checks: if request.auth != null
- Restrict write access by user role
- Validate data before writes
- Use Firebase App Check
- Never store passwords in plain text
